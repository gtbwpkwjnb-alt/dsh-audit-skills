# platforms/ 说明

本目录的六个平台文件（claude / codex / cursor / default / workbuddy / zcode）仅记录各平台的特征信息（安装路径、归档路径、市场展示文案、Agent 模型约束等），供 Agent 在执行审查时参考。

- **无脚本消费**：`scripts/` 下的三个脚本均不读取本目录文件。
- **权威来源**：扫描路径与触发词的唯一权威来源是 `config.yaml` 与 `SKILL.md`（触发词矩阵）；本目录文件不定义扫描路径，也不重复定义触发词。
- **只读底线**：平台文件中的权限声明必须与技能的只读底线一致，不得声明 `write` 类权限。
