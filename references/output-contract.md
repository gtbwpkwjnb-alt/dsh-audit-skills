# 审计输出与事实契约

默认只读；每个结论都有证据与状态，缺失项为 null/unavailable，不用默认值、样例或常识补分。

| 状态 | 含义 |
|---|---|
| observed | 当前文件、命令、可归因事件直接观察，附路径与时间 |
| market_observed | 已读取并核验的外部证据，附 URL 与日期 |
| inferred | 从已观察事实推导，附规则与输入 |
| estimated | 近似公式，附假设及误差限制 |
| unavailable | 未获取、不可信或不可归因，不计分、不排序 |

安装、启用、UI 可见、调用和运行通过分开。词命中不是适用性实测；配置存在不是启动成功；静态规则不是安全认证。
没有事件不是零使用；没有市场数据不是零价值。内置 registry 对齐不证明上游最新。
容量仅 estimated；安装数量或字节/4 不等于实际注入 token。
每条操作遵循 actions-schema.md：建议执行、步骤、执行 Agent、验证、回滚、状态；不自动安装、更新或改配置。
当前会话报告无需导出确认；写文件必须有明确导出请求，脚本 --output 不覆盖现有文件。
报告 complete 仅表示约定扫描完成，不保证全部资产可运行；未知维度继续披露。
分别输出 scan_status 与 assessment_status；首次全景逐模块交代已查/推断/估算/未查，避免把 CLI 执行成功称为全部可用。
同类补证建议合并为一组，JSON 保留每个目标的行动计划；不输出“处理 0 个问题”，不建议无差别为所有工具联网补分。
MCP 局部分数必须显示已查维度覆盖；上下文必须标明目录、假定窗口与未纳入的资产。
