# Agent 派单证据

本模块为推荐提供证据，不执行 Agent 合并、归档或发布。

区分当前宿主可选 Agent、历史 profile 快照、声明能力矩阵和实际派单记录。
capability-dimensions.yaml 是声明的启发式基线；读取成功不证明宿主存在这些角色或模型。
能力重叠为 inferred；频次差异可能来自正常分工，不证明误派，仅作抽查候选。

无可归因派单记录时 status=unavailable，不把空 overlap_pairs 显示为已验证正常。
有记录时披露客户端、时间窗、覆盖与 unmapped_agents，不将未映射角色补为零能力。
候选须含角色对、共享能力、记录来源、规则和需核验案例；无失败案例不直接建议合并或归档。
模型费用、速度与成功率仅用可验证数据，不从角色或模型名称推算。

交接：抽查代表任务 → 判断是否错路由 → 有实证才提出边界调整 → 按已有授权实施并回放测试。
