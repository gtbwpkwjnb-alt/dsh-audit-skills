# 本地健康证据清单

服务“技能/插件推荐操作”，不设独立维护或监测工作流。

| 维度 | 可核验证据 | 不能推出的结论 |
|---|---|---|
| 来源与元数据 | SKILL.md、UI metadata、manifest 的解析与路径 | 存在不代表启用、UI 可见或运行通过 |
| 引用 | 当前包及允许上级目录的文件 | 路径存在不证明脚本可运行 |
| 版本 | VERSION、manifest、版本目录及来源路径 | 本地版本不证明最新，mtime 不证明发布时间 |
| 使用 | 限定客户端、时间窗的可归因事件 | 无记录不等于零使用 |
| 冲突 | 不同活动来源、触发范围及错路由案例 | 临时缓存差异或词相似不等于故障 |
| 安全 | 具体规则命中及人工核验 | 静态匹配不是安全认证 |
| 跨平台 | 同名来源的版本、路径和作用域 | 未查平台不能标一致 |

当前 CLI 实现来源、元数据、引用和静态评分；上游版本、实际运行、安全、跨客户端一致须单列已查或 unavailable。
健康局部分数须注明覆盖，不依据高分替代未测维度或单独归档。
plugin-install-* 临时副本与 cached_only 保留为发现记录，不当作活动冲突；真实冲突给出双方路径。
优先具体阻断/风险，再修复，再按当前需求补证；共同缺口聚合，不重复生成相同步骤。
实施建议遵循 actions-schema.md；不自动归档、写配置、保存历史或安排定时任务。
