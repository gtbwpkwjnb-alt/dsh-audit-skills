# 上下文容量估算

安装数或文件大小不等于实际注入；不依据估算单独隐藏/卸载。

当前 CLI 边界：
- Skills：指定用户目录一级 SKILL.md 的完整 frontmatter description，不包括全部系统/插件技能。
- MCP：指定配置服务；优先 Reasonix 缓存工具数，缺失时假设每服务10工具、每工具300 tokens。
- Agent：指定目录 profile 文本或历史 metadata 描述，不证明当前注入。
- 文本换算：中文字符/1.8、其他字符/4；窗口假设200000 tokens，不是当前模型规格。

输出注明目录、计数口径、覆盖、公式和缺失维度。45项安装资产与12项用户技能不是同一总体，不可直接比较。
百分比和等级为 estimated/inferred，不能推出空间不足或必须精简。
仅当前宿主的实际注入记录/测量可校准，旧客户端实测不泛化到其他宿主。

先核验加载机制，再比较目标技能入口；精简后保留触发和边界并回测。
使用/匹配证据缺失为 unavailable，不填零计算精简价值；隐藏/卸载遵循 ecosystem-optimization.md。
不自动保存历史、调整窗口、修改 MCP 或删除 profile。
